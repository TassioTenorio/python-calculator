# Simple Calculator

A command-line calculator developed with Python, featuring basic arithmetic operations, input validation, and exception handling.

The application provides an interactive menu that allows users to perform calculations, handle invalid inputs, and safely manage mathematical operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Exception handling for invalid inputs
- Protection against division by zero
- Validation of non-finite numbers (`NaN` and `Infinity`)
- Interactive command-line menu
- Exit option

## Technologies

- Python 3
- `os` module
- `math` module

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/TassioTenorio/simple-calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd simple-calculator
   ```

3. Run the application:

   ```bash
   python calculator.py
   ```
